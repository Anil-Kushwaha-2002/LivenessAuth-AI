# LivenessAuth-AI
A Lightweight Offline Facial Recognition and Liveness Detection System for Zero-Network Environments

## Overview

LivenessAuth AI is a lightweight offline facial recognition and liveness detection system designed for remote and zero-network environments.

The solution enables secure user authentication on Android and iOS devices without requiring internet connectivity. It combines facial recognition, liveness detection, local storage, and cloud synchronization capabilities to ensure uninterrupted operations in field environments.

## Key Features

* Offline Facial Recognition
* Offline Liveness Detection
* Anti-Spoofing Protection
* Lightweight AI Models (<20 MB)
* Fast Authentication (<1 Second)
* React Native Compatibility
* Secure Local Storage
* AWS Sync and Purge Mechanism

## Technology Stack

* React Native
* Python
* FastAPI
* OpenCV
* MobileFaceNet
* MiniFASNet
* ONNX Runtime
* SQLite
* AWS

## Proposed Architecture

Camera → Face Detection → Liveness Detection → Face Recognition → Authentication → Local Storage → Cloud Sync
